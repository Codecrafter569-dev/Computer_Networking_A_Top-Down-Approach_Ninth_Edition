Section 1.1

R1. What is the difference between a host and an end system? List several different types of end systems. Is a Web server an end system?

In computer networking, there is no real difference between a host and an end system. They are usually used to mean the same thing: a device at the edge of the Internet that runs network applications and sends/receives data.

Examples of end systems include:

- desktop computers
- laptop computers
- smartphones
- tablets
- servers
- smart TVs
- game consoles
- IoT devices such as smart cameras and smart speakers

Yes, a Web server is an end system because it is a device connected to the network that communicates with other hosts.

R2. The word protocol is often used to describe diplomatic relations. How does ChatGPT describe diplomatic protocol?

A diplomatic protocol is a set of accepted rules, customs, and procedures that guide communication and behavior between diplomats, governments, and official representatives.

Just like a network protocol, diplomatic protocol defines:

- what actions are allowed
- the order in which things should happen
- how parties should behave
- how messages or formal exchanges should be handled

So, in simple words, diplomatic protocol is a rulebook for proper official interaction.

R3. Why are standards important for protocols?

Standards are important because they make it possible for different devices, programs, and networks to work together correctly.

If everyone followed different rules, communication would fail. Standards help by:

- allowing interoperability between equipment from different companies
- making communication reliable and predictable
- reducing confusion and mistakes
- encouraging widespread adoption
- lowering cost because many vendors can build compatible products

In short, standards are what make protocols useful on a large scale.

R5. Is HFC transmission rate dedicated or shared among users? Are collisions possible in a downstream HFC channel? Why or why not?

In HFC (Hybrid Fiber Coax), the transmission rate is generally shared among users in the same neighborhood or cable segment.

This means many users share the same available capacity, so if more people are active, the speed may drop.

For the downstream HFC channel, collisions are not possible in the usual sense, because the cable company broadcasts data downstream from the headend to the users. The downstream channel is controlled by the provider, so user devices are not all transmitting at the same time on that channel.

Collisions are mainly a concern on the upstream side, where many users may try to send data back at the same time.

R9. HFC, DSL, FTTH, FWI, and LEO satellite are all used for residential access. For each of these access technologies, provide a range of transmission rates and comment on whether the transmission rate is shared or dedicated.

Here is a simple comparison:

1. HFC

- Typical rate range: about 10 Mbps to 1 Gbps or more, depending on the system
- Shared or dedicated? Shared
- Comment: Users in the same cable area share capacity, especially on the cable segment.

2. DSL

- Typical rate range: about 1 Mbps to 100 Mbps, depending on distance and DSL type
- Shared or dedicated? Mostly dedicated from the home to the provider’s local equipment
- Comment: Speed depends heavily on distance from the telephone exchange.

3. FTTH

- Typical rate range: about 100 Mbps to multiple Gbps
- Shared or dedicated? Often dedicated on the local access link, though some provider networks use shared aggregation
- Comment: Usually gives the best residential performance.

4. FWI (Fixed Wireless Internet)

- Typical rate range: about 10 Mbps to several hundred Mbps
- Shared or dedicated? Usually shared
- Comment: Capacity depends on tower load, distance, and signal quality.

5. LEO satellite

- Typical rate range: about 25 Mbps to 250 Mbps or more
- Shared or dedicated? Shared
- Comment: Good for remote areas, but performance can vary with congestion and weather.

R10. Describe the most popular wireless Internet access technologies today. Compare and contrast them.

The most popular wireless Internet access technologies today are:

1. Wi-Fi

Wi-Fi is used in homes, schools, offices, and public places.

- Works over short distances
- High speed
- Low cost
- Best for local access inside buildings

2. Cellular networks (4G and 5G)

Cellular networks connect mobile phones and portable devices.

- Works over large geographic areas
- Supports mobility
- 5G is faster and lower-latency than 4G
- Speed depends on signal strength and network load

3. Fixed wireless access

This provides Internet to a home or building using a wireless link to a base station.

- Useful where cables are hard to install
- Can offer decent speed
- Performance depends on distance and obstacles

4. Satellite Internet

Satellite Internet is used in remote or rural areas.

- Very wide coverage
- Works where other access is unavailable
- Usually higher delay than other wireless systems
- Newer LEO satellite systems reduce delay compared to older satellite systems

Comparison

- Wi-Fi is best for local indoor networking.
- Cellular is best for mobility.
- Fixed wireless is useful for home access without cables.
- Satellite is best for very remote locations.

Overall, wireless technologies trade off speed, range, mobility, and cost.
